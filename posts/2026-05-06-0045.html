📌 核心功能更新详情

Git 插件原生支持：Skill 生态里程碑

v2026.5.4 将 git: 协议插件安装提升为一等公民，意味着开发者可以直接从任意 Git 仓库安装、更新和管理 Skill，无需经过 ClawHub 或其他中心化集市：

  • Ref checkout 支持：可指定分支、tag 或 commit 安装特定版本
  • Commit metadata 记录：安装的插件会记录来源 commit，便于追溯和审计
  • Normal scanner/staging：与本地插件一致的扫描和 staging 流程
  • plugins update 支持：openclaw plugins update 会自动检测并更新所有通过 Git 源安装的插件

这一更新对企业和闭源 Skill 开发者意义重大：不再依赖 ClawHub 发布流程，私有仓库即可作为 Skill 源，CI/CD pipeline 可直接推送更新。

Google Meet + Twilio：会议 Agent 场景补全

此前 OpenClaw 已支持通过 Chrome DevTools Protocol 控制浏览器加入 Google Meet 并获取实时字幕。v2026.5.4 进一步打通 Twilio dial-in 入会通道：

  • 通过 Twilio 电话号码拨号入会，无需浏览器参与
  • 音频流通过 realtime Gemini voice bridge 处理，支持 paced audio（节奏化音频）
  • 完整的 pre-connect DTMF 和初始问候交接日志，便于生产环境排障

这意味着 OpenClaw 现在可以以 "电话参会者" 身份 7×24 小时驻留会议，适用于会议纪要自动生成、合规录音、待办提取等场景。

SDK tools.invoke：从 Gateway 到应用的双向桥接

新增的 SDK-facing tools.invoke RPC 接口允许外部应用通过标准 HTTP 调用触发 Agent 工具执行，返回类型化的 approval/refusal 结果。这为 "OpenClaw 作为企业后端服务" 的架构模式提供了官方支持——前端应用可以像调用普通 API 一样触发 Agent 能力，同时保留人工审批的插槽。
