📚 精选 Skill 学习指南

1. 从 ClawHub 导入 Skills

OpenClaw、CoPaw 和 ArkClaw 均支持从 ClawHub 一键导入技能。对于 OpenClaw 用户，使用 clawhub install <skill-name>；CoPaw 用户可通过配置文件的 skills 目录自动加载。建议新手从天气查询、文件整理、定时任务等基础 Skill 开始，逐步扩展到自定义开发。

2. Hermes Agent 的 Skill 自进化机制

Hermes 的独特之处在于无需手动编写 Skill——Agent 会在成功完成任务后自动提取策略，生成结构化 Skill 文档存入 MEMORY.md。后续遇到相似任务时，通过 SQLite 全文检索自动复用。开发者只需关注"第一次教它做事"，后续它会自己越用越聪明。

3. 多平台接入配置速查

WorkBuddy 支持微信/企微/QQ/飞书/钉钉一键接入；CoPaw 原生支持钉钉/飞书/QQ/Discord/iMessage；ArkClaw 深度绑定飞书/钉钉/企微。对于国内用户，建议优先测试企微和飞书机器人——这两个平台的 Webhook 和 API 稳定性最佳，且企业内部审批流程最成熟。
