📌 核心功能更新详情

acpx：OpenClaw的"Agent调度中枢"

acpx基于JetBrains和Zed推出的ACP（Agent Client Protocol）协议，将原本各说各话的编码Agent收拢为统一命令面。核心三种协作模式已成熟：

  • 流水线式：Gemini分析架构 → Codex执行重构 → Claude补充测试 → OpenCode生成文档
  • 并行式：Codex同时实现前后端，Claude并行生成测试，OpenClaw整合结果
  • 专家会诊式：多Agent给出不同方案，OpenClaw综合评估选最优解

安装命令：npm install -g acpx@latest，调用示例：npx acpx@latest codex -s pr-842 "Review PR #842"

📚 精选 Skill 学习指南

🔧 acpx Skill 安装与配置

在OpenClaw中使用acpx需要安装两部分：OpenClaw acpx插件 + acpx npm包。

# 1. 安装OpenClaw插件
openclaw plugins install @openclaw/acpx

# 2. 安装acpx npm包
npm install -g acpx@latest

# 3. 安装claude/codex的skill
npx acpx@latest --skill install acpx --agent codex --scope user

# 4. 配置OpenClaw（config.json）
{
  "plugins": {
    "allow": ["acpx"],
    "entries": {
      "acpx": {
        "enabled": true,
        "config": {
          "command": "acpx",
          "permissionMode": "approve-all"
        }
      }
    }
  },
  "acp": {
    "enabled": true,
    "backend": "acpx",
    "defaultAgent": "claude",
    "allowedAgents": ["claude", "codex", "cursor", "gemini", "pi"]
  }
}
