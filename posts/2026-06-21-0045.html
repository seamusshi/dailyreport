📌 核心功能更新详情

🛠️ SKILL.md 规范：技能的 DNA

SKILL.md 是 OpenClaw 技能系统的核心契约文件，采用 YAML Frontmatter + Markdown 的混合格式：

---
name: my-calendar-sync
description: Syncs meetings from Gmail to Notion daily
metadata.openclaw:
  requires:
    bins: ["node"]
---
When the user asks to sync their calendar, call the Google Calendar API
using the provided OAuth token, retrieve today's events, and create a
Notion page for each meeting. Format the output as: [Time] [Title] [Attendees].
  • 声明式配置：YAML 部分定义技能元数据、依赖项、权限需求
  • 自然语言指令：Markdown 部分向 LLM 描述技能的行为逻辑与输出格式
  • 即时生效：将技能目录放置于 <workspace>/skills/ 后立即可用，无需重启
  • 加载优先级：内置技能 (Priority 6) > 用户自定义 (Priority 5) > ClawHub 安装 (Priority 3)

🧠 Capability Evolver：技能的自我进化

Capability Evolver 是 OpenClaw 最具前瞻性的功能之一，允许 Agent 在运行过程中自我优化提示词：

  • 机制：Agent 评估任务执行效果，自动调整 SKILL.md 中的指令描述
  • 风险：中等——技能文件被修改可能影响行为一致性，建议仅在开发环境启用
  • 适用场景：长期运行的自主 Agent、需要持续学习的个性化助手
  • 可靠性评分：8.5/10（DigitalApplied 2026 年 2 月评测数据）

🌐 浏览器自动化：CDP 协议毫秒级交互

OpenClaw 通过 Chrome DevTools Protocol (CDP) 实现生产级的浏览器自动化：

  • 绕过 GUI 渲染，直接与浏览器内核通信，实现毫秒级元素交互
  • Snapshot 系统为页面元素分配唯一 ID，AI 通过简单数字 ID 即可操作
  • 支持批量表单填写、结构化数据提取、竞品价格监控
  • 注意：Token 消耗极高，且对 DOM 变化敏感，生产环境建议配合 API 驱动技能使用

🧠 记忆系统：从会话记忆到向量记忆

OpenClaw 的多层记忆架构是其区别于普通 Chatbot 的核心能力：

  • 持久记忆：跨会话保持用户偏好、历史决策、项目上下文
  • 向量记忆：本地部署支持完整向量嵌入检索，Kimi Claw 等云托管版本暂不支持
  • Heartbeat 机制：30 分钟周期主动检查，支持 cron 定时任务与条件触发
  • episodic / semantic 双轨： episodic 记忆保存任务历史，semantic 记忆构建知识图谱
