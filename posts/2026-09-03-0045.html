🦞 OpenClaw 官方动态

🔖 最新稳定版：v2026.8.2（2026-08-02）

发布时间：2026年8月2日 | 类型：稳定版本

本次版本被官方定位为"Home beside your work"，核心围绕用户体验、安全升级和语音可靠性展开：

  • Home 智能体 — Control UI 新增 Home 按钮，将个人智能体置于工作流旁，一键触达
  • Linux 桌面伴侣 — 专为 Linux 桌面打造的 companion 应用，支持后台会话运行
  • 后台会话（Background Sessions） — 无需切换页面即可启动后台工作流，提升多任务效率
  • 更安全的升级机制 — 保留更新的配置、阻止不完整的会话迁移、支持失败后安全回滚（#118244, #90551, #134206）
  • 可靠的回复与语音 — 工具执行后返回最终答案、修复语音输出中的内部推理泄漏、保持浏览器 Talk 通话稳定性
  • 可选图像解码更新 — Sharp 依赖升级至 0.35.4，修复 libheif 相关漏洞
  • 工作区权限改进 — 权限变更实时应用到活跃运行，云工作者的会话工具策略保持一致
  • 私有诊断数据脱敏 — macOS 应用日志中显式标记私有字段，Clawdock 诊断不再暴露凭证
  • 四个新主题 — 界面个性化选项进一步丰富

升级建议 ClawStat.us 评估：值得升级，但请先备份。3 个可信阻塞性问题已确认（Linux WebKit 崩溃、内存重索引膨胀、主会话恢复延迟），均非广泛性问题。

📌 核心功能更新详情

🏠 Home 智能体 — 工作流旁的数字伙伴

v2026.8.2 最重要的产品级更新是 Control UI 中的 Home 入口。它不是一个独立功能，而是一种新的交互范式：

  • Home 按钮常驻于 Control UI 侧边栏，随时触达个人智能体
  • 支持"Ask OpenClaw"助手 dock，布局兼容已保存配置
  • 与 Pages 编辑器并存，不干扰当前工作流

这意味着 OpenClaw 正从"任务工具"向"常驻数字伙伴"进化。

🐧 Linux 桌面伴侣 + 后台会话

Linux 用户获得原生级体验：

  • Linux Desktop Companion — 专为 Linux 桌面环境设计的 companion 应用
  • 后台会话 — 可在不切换页面的情况下启动后台工作，适合长时间运行的任务
  • 从 New Session 创建后台会话 — 一键启动，无需额外配置

已知问题 Linux AppImage 版存在 WebKitWebProcess SIGABRT 崩溃问题（#136148），建议关注修复进度。

🔒 更安全的升级机制

v2026.8.2 花大力气解决了升级过程中的数据安全问题：

  • 保留更新配置 — 升级时不再覆盖用户的新配置
  • 阻止不完整迁移 — 会话迁移未完成时不会声称成功
  • 失败后自动恢复 — 更新失败后可安全回滚到已验证的版本
  • 迁移安全协调 — 自动代理数据库维护与当前所有者协调
  • 修复遗留 v17 代理数据库 — 支持更老版本的会话恢复

🎙️ 语音可靠性大幅提升

语音交互是 Agent 产品"自然感"的核心，v2026.8.2 修复了多个关键问题：

  • 内部推理内容不再泄漏到语音输出
  • 工具生成的音频在交付过程中不再丢失
  • 浏览器 Talk 通话建立后的后续回合正常工作
  • 实时语音 Agent 咨询支持 Talk/Meet/VoiceCall

🛡️ 16 次事故 + $1.50 计算成本 = 自动恢复系统

开发者 Alex Rezvov 记录了一天内的生产部署经历：

  • 心跳任务每 15 分钟泄漏内部推理 token 到 Telegram
  • 15 篇文章摘要生成成功但从未交付
  • Cron 任务因 gateway token 不匹配静默失败

他的解决方案：编写 watchdog 脚本每 5 分钟 ping Agent，无响应则自动 kill 并重启 Gateway。总计算成本：$1.50/天。这恰恰说明 OpenClaw 的价值不在于"永不崩溃"，而在于"让恢复变得便宜且自动化"。
