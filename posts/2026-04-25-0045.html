1. Hermes Agent GEPA： Genetic Evolution of Prompt Architectures

Hermes Agent 的核心差异化是自进化机制 GEPA，每 15 次工具调用触发一次自我评估，生成提示策略的突变变体，保留能提升任务完成率的版本。

  • 自改进循环：Evaluate → Mutate → Select → Apply，无需人工干预
  • 技能文档自动生成：成功经验转换为 Markdown 格式 Skill，存入 ~/.hermes/skills/
  • 三层记忆系统：SQLite + FTS5 实现 ~10ms 搜索 10K+ Skills
  • 性能提升：ICLR 2026 Oral 论文验证，编码基准测试提速 33-38%

与 OpenClaw 的架构之争：

维度Hermes Agent (Agent-First)OpenClaw (Gateway-First)
调试 evolved prompts 可能漂移，难审计确定性编排，可复现 trace
合规自修改可能产生未授权工具模式策略引擎，细粒度访问控制
重复任务GEPA 持续优化，效率显著提升静态提示，依赖人工调优
