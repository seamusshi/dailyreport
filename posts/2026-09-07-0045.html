开源黑马
⭐ GitHub: 178K+ 🔧 40+ 内置工具 💬 27+ 消息平台 📅 2026.02 发布

核心架构："学习循环优先" — 每次任务完成后进入反思阶段，提取可复用推理模式并持久化为 Skill。Agent 越用越聪明，20+ 次类似任务后执行速度提升 2-3 倍。

与 OpenClaw 的根本差异：Hermes 是"Agent 优先"（能力从 Agent 执行历史中同心增长），OpenClaw 是"网关优先"（能力从中心 Gateway 向外扩展）。前者适合长期陪伴型个人助手，后者适合团队协作和多渠道编排。

Hermes Agent vs OpenClaw：架构哲学的深层对决

两个框架代表了 AI Agent 设计的两种根本世界观：

维度Hermes Agent（进化派）OpenClaw（工程师派）
核心哲学学习循环优先，Agent 越用越聪明网关优先 + 本地优先，统一编排
能力增长从 Agent 执行历史中同心增长从中心 Gateway 向外扩展
技能系统自动生成、自动优化、自我改进社区共享、手动安装、版本管理
记忆架构三层记忆（工作/语义/情景）+ FTS5 搜索持久会话记忆 + AGENTS.md/USER.md
适用场景长期陪伴型个人助手、研究助理团队协作、多渠道编排、企业自动化
部署形态CLI + TUI + 桌面应用Gateway + Web UI + 原生应用 + IM 集成

关键洞察：这不是"谁替代谁"的问题。Hermes 适合"一个人 + 一个 Agent 长期共处"，OpenClaw 适合"一个团队 + 多个 Agent 协作运转"。未来的企业架构可能是 OpenClaw 作为编排层，Hermes 作为特定 Agent 的运行时。

Skill 选型指南：OpenClaw Skills vs Plugins vs MCP Servers

OpenClaw 生态中有三种扩展方式，选择取决于场景：

  • Skills（SKILL.md）：最适合编排多个工具形成工作流。复杂场景（如 RAG Pipeline、Agent Orchestrator）只能用 Skill 实现。可通过 ClawHub 安装：npx clawhub@latest install skill-name
  • MCP Servers：适合为 Agent 添加单一工具能力（如连接某个数据库、调用某个 API）。遵循 Model Context Protocol 标准，跨框架兼容。
  • Plugins：传统扩展方式，逐渐被 MCP 替代。仅当没有对应 MCP Server 时考虑。

ClawHub 目前收录 5,700+ Skills，覆盖开发、运维、数据分析、内容创作、财务等全场景。
