🔧 2026.5.2 稳定版回顾 —— 性能回归修复与插件架构重构

5 月 3 日发布的 2026.5.2 稳定版解决了 4 月底 2026.4.29 引入的 CPU 占用过高、WebUI 卡顿等性能回归问题。核心改进包括：外部插件安装流程全面重构（npm-first 迁移、过期配置修复、缺失包载荷处理、Beta 通道回退机制）；Gateway/Agent 热路径精简优化；新增 /think default 和 /fast default 命令清除会话覆盖并继承配置默认值。这是一个"修内功"的版本，没有 flashy 新功能，但显著提升了大规模部署的稳定性。

来源：OpenClaw GitHub / openclaw.com.au/updates

🌐 浏览器控制架构升级 —— 从 Chrome 扩展到 Existing-Session 模式

OpenClaw 正在从 legacy Chrome 扩展 relay 路径迁移到 existing-session / user 浏览器附着模式，支持通过 userDataDir 加载 Chromium 家族配置文件。这意味着 Agent 可以直接附着到已登录的真实浏览器会话，保留真实登录态和审批流程。相比脆弱的扩展中间层，新模式大幅提升了浏览器自动化在企业场景中的可靠性。

来源：OpenClaw GitHub PR #48170 / PR #47630

📌 核心功能更新详情

统一模型目录注册（2026.5.9-beta.1）

新增 providerCatalogEntry 清单、共享媒体列表帮助、实时目录缓存和 per-model 视频能力叠加层。OpenClaw 不再将模型视为简单的 API 端点，而是建立完整的提供商能力注册表，使 Agent 在多模态任务中自动选择正确的模型和格式。这是从"管道工具"到"智能编排平台"的关键一步。

Cron 状态分离与 Gateway 稳定性（2026.4.20+）

将 cron 执行状态从 jobs.json 拆出到 jobs-state.json，实现任务定义与执行状态的解耦。配合更早触发的会话修剪和增强的 token 用量报告（支持缓存目录和配置模型的定价计算），解决了大规模部署中 Gateway 启动延迟和状态膨胀问题。

语音与浏览器自动化全面生产就绪（2026.4.25）

Voice/Telemetry/Browser Automation 三大模块完成生产就绪化升级：新增 Azure Speech、小米、ElevenLabs v3、火山引擎等 6 大 TTS 提供商支持；聊天级自动 TTS 控制、Personas 角色系统和 per-agent 覆盖配置。这意味着 OpenClaw 的语音交互能力已可支撑企业级客服、语音助手等场景。

安全加固：Fail-Closed 默认策略

近期版本累计安全改进：Slack 交互事件更严格遵循所有者白名单、附件路径解析失败时关闭（fail-closed）、危险安全审计标志无法通过模型面向的 Gateway 配置工具新启用、浏览器 SSRF 行为规范化、Control UI 替换 ReDoS 风险的 Markdown 解析器。整体趋势：更少的隐藏转换，更好的运行时清晰度，更强的边界纪律。
