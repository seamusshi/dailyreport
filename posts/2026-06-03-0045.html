精选 Skill 学习指南

Skill #1：Summarize（内容摘要）

下载量10K+的热门Skill，支持对长文章、会议记录、PDF文档智能摘要。提供四种模式：bullet（5-10要点）、executive（200-300字管理报告）、detailed（500-800字深度分析）、action-items（提取待办事项）。推荐搭配Claude模型处理长文本，GPT-4o处理多语言摘要。

claw install summarize

Skill #2：Browser-use（浏览器自动化）

让Agent像人类一样浏览网页、填写表单、提取数据。配合Crawl4AI可实现复杂爬虫工作流。适合竞品监控、价格追踪、信息收集等场景。

Skill #3：Daily Briefing Agent

定时生成个性化日报，整合邮件摘要、日程提醒、新闻推送、股票行情。支持通过飞书/企业微信/钉钉推送。

Skill #4：Tavily Search（联网搜索）

高质量AI搜索引擎Skill，专为Agent优化。相比传统搜索，返回结构化数据供Agent直接使用。注意：在NemoClaw等沙箱环境中使用可避免敏感代码泄露风险。
