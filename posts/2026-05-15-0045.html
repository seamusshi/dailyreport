📌 核心功能更新详情

语音模式可用性修复（v0.10.3）

修复了部分 TTS 提供商（包括 Azure Speech、ElevenLabs v3、火山引擎等）在长时间会话中可能出现的断连和音频卡顿问题。同时优化了语音模式下的错误恢复机制，当某个 TTS 提供商失败时自动回退到备用提供商。

Cron 表达式验证增强

改进了 Cron 任务的表达式解析和验证逻辑，现在会在任务创建阶段就检测非法表达式并给出明确的错误提示（如"第 5 个字段范围超出 0-6"），避免此前"静默失败"导致的任务不执行问题。

Workspace 路径解析修复

修复了 Workspace 目录中包含符号链接（symlink）或特殊字符时的路径解析异常，确保 Agent 在复杂文件系统布局中仍能正确读写工作目录。

MCP 协议原生支持深化

随着 MCP 成为行业标准，OpenClaw 对 MCP Server 的连接稳定性进行了多项底层优化，包括连接池管理、心跳检测和自动重连机制，确保长时间运行的 Agent 与外部工具之间的通信可靠。
