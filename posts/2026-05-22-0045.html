📌 核心功能更新详情

Hermes Agent Transport 层重构：从单一通道到多协议矩阵

Hermes v0.14.0 对传输层进行了彻底的重构，标志着其从实验性项目走向生产级框架：

  • Transport ABC 抽象层：将格式转换和 HTTP 传输从 run_agent.py 抽离到 agent/transports/ 目录，支持插件式扩展
  • AnthropicTransport：Anthropic Messages API 原生路径
  • ChatCompletionsTransport：OpenAI 兼容提供商的默认路径
  • ResponsesApiTransport：OpenAI Responses API + Codex build_kwargs 连线
  • BedrockTransport：AWS Bedrock Converse API 传输层

这意味着 Hermes 不再绑定单一 API 格式，企业可以在 AWS、NVIDIA、Vercel、OpenRouter、原生提供商之间自由切换，无需重写 Agent 逻辑。

NemoClaw：NVIDIA 官方加持的 OpenClaw 安全增强版

NVIDIA 在 RTX AI Garage 博客中正式宣布 NemoClaw：

  • 定位：开源技术栈，优化 OpenClaw 在 NVIDIA RTX PCs、RTX PRO 工作站和 DGX Spark 上的体验
  • 核心改进：增加安全性、支持本地模型推理、提升 Token 生成速度
  • WSL2 支持：现已支持 Windows Subsystem for Linux，扩大开发者覆盖
  • 硬件搭档：推荐配合 Qwen 3.6 系列（27B/35B）通过 llama.cpp / LM Studio / Ollama 本地运行

NVIDIA 的背书意味着 OpenClaw 生态获得了硬件巨头的官方认可，从"软件框架"升级为"软硬件协同生态"。

ClawHub 安全治理升级：从"野蛮生长"到"有序监管"

随着 ClawHub 技能数量突破 13,700，安全问题成为社区焦点：

  • 审计数据：Koi Security、Bitdefender、Snyk 三家机构审计显示，12%-36% 的第三方 Skill 存在漏洞或恶意载荷
  • VirusTotal 集成：2026 年 2 月上线，所有新提交 Skill 生成 SHA-256 哈希与 VirusTotal 数据库交叉验证
  • 发布门槛：GitHub 账号至少 1 周老，无身份验证、无代码审查、无包签名
  • 官方推荐验证流程：查 VirusTotal 报告 → 核验 GitHub 仓库真实性 → 阅读 SKILL.md 源码 → 固定版本号安装 → 隔离环境测试

Skywork 2026 年 3 月 24 日统计：13,700 社区 Skill 中仅 53 个为官方认证。安全验证已成为 Skill 安装的必修课。
