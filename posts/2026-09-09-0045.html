OpenClaw 2026 安全态势：8 个 CVE 全程追踪

2026-02 至 2026-04 · 多版本安全补丁发布

2026 年是 OpenClaw 安全成熟度跃升的关键一年。从年初的 CVE-2026-25253（跨站 WebSocket 劫持，CVSS 8.8） 到年中的 CVE-2026-32977（沙箱 WriteFile 路径竞争绕过），安全团队保持了高强度的响应节奏。 关键版本 v2026.2.15、v2026.2.21、v2026.3.11 均包含关键安全补丁。

📌 核心功能更新详情

CVE-2026-25253

跨站 WebSocket 劫持（CSWSH），CVSS 8.8 高危。攻击者可通过一键点击实现远程代码执行。已修复。

CVE-2026-27002

Docker 沙箱容器逃逸：未验证的 bind mount 配置注入，可启用危险 Docker 选项。v2026.2.15 引入 HostEnvSanitizer 和沙箱 Docker 设置拦截。

CVE-2026-27009

存储型 XSS：Control UI 渲染 assistant identity 时未对 script context 做安全转义。v2026.2.15 引入 CSP 策略（script-src 'self'）。

CVE-2026-22177

RCE 漏洞：环境变量配置注入可导致远程代码执行。v2026.2.21 引入集中式 HostEnvSanitizer 模块。

CVE-2026-32046

沙箱绕过：OPENCLAW_BROWSER_NO_SANDBOX 配置可导致浏览器沙箱失效。v2026.2.21 默认禁用 no-sandbox。

CVE-2026-32977

沙箱边界绕过：writeFile commit 步骤使用未锚定的容器路径。v2026.3.11 修复路径验证逻辑。

CVE-2026-41362

Zalo webhook replay-dedupe 缓存跨账户共享，可导致消息静默抑制。v2026.3.31 修复缓存 key 作用域。

CVE-2026-22175

exec allowlist 绕过：busybox/toybox shell wrapper 导致 allow-always 持久化到错误路径。v2026.2.23 加固 wrapper 检测。

💡 分析师观察：OpenClaw 2026 年的安全事件密度显著高于往年，这并非坏事—— 恰恰说明项目影响力扩大，吸引了更多安全研究者审视。从响应速度看， 高危漏洞平均修复时间约 2-4 周，处于行业中等偏上水平。 建议企业用户保持自动更新，并关注 openclaw doctor 的安全审计建议。

安全自查清单
  1. 查看 skill 的 GitHub 仓库：stars 数、最近更新时间、issue 响应速度
  2. 审查 package.json 依赖：是否有可疑或过度授权的依赖包
  3. 检查 skill 请求的权限范围：是否超出其声明的功能所需
  4. 在隔离环境中先测试：使用 Docker 沙箱或临时 VPS 运行未知 skill
  5. 关注 ClawHub 官方安全公告：及时移除有漏洞的 skill
