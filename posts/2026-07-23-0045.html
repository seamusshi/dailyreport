📌 核心功能更新详情

Skill Workshop：AI 自动为你写技能

这是 v2026.7.2 中最令人兴奋的功能之一。Skill Workshop 会扫描你的历史会话，识别重复出现的模式（比如"每天早上检查邮件、日历、天气并发送摘要"），然后生成一个保守的、可 review 的技能草稿。

它不是盲目地复制粘贴，而是会：识别触发条件 → 提取工具链 → 生成 SKILL.md → 标记需要人工确认的参数。这意味着你的 agent 可以从"执行者"进化为"学习者"——它观察你的工作流，然后把它固化成可复用的技能。

Cloud Workers：从个人电脑到分布式云

Cloud Workers 将 OpenClaw 的会话执行从本地 Node.js 进程扩展到远程 worker 集群。这意味着：

  • 重度计算任务（如代码编译、大规模数据分析）可以 offload 到云端
  • 多个 agent 可以并行运行在不同 worker 上，互不干扰
  • 会话状态仍然保留在 gateway，但执行发生在"最近的"worker

这对企业部署尤其重要——IT 部门可以在内部 Kubernetes 集群上部署 workers，而开发者无感知地使用 sessions_spawn 等 API。

Paired-node Coding Agents：打破设备边界

这个功能让 OpenClaw 可以"发现"并连接到运行在其他设备上的编码会话——无论是你的另一台电脑上的 OpenCode、Pi，还是云端的 Codex / Claude Code 会话。然后，它可以通过流式 CLI agent 运行继续这些会话。

想象这个场景：你在办公室用 Claude Code 写了一半的功能，回家后在 OpenClaw 上说"继续我办公室那台电脑上的 session"——它会自动找到、连接、并继续。这不是科幻，是 v2026.7.2 beta 正在验证的功能。

Skills MCP Bridge：技能即工具

PR #94400（以及后续的 #106359 MCP isolation）正在将 OpenClaw 的技能体系与 MCP（Model Context Protocol）标准对接。核心变化：

  • 每个 Skill 可以通过 JSON-RPC handler 暴露为 MCP tool
  • Lazy HTTP server loading：只有被调用时才启动 skill 的 MCP server
  • Optional /mcp endpoint：让外部 MCP client 也能调用 OpenClaw skills

这意味着 OpenClaw 的 5700+ 社区技能正在变成整个 MCP 生态的工具库。一个 Cursor 或 Claude Desktop 用户，理论上可以直接调用你在 OpenClaw 里安装的 weather 或 stock_finance_data skill。

📚 精选 Skill 学习指南

Skill 1：browser（浏览器自动化）

OpenClaw 的浏览器 skill 是基于 Chrome DevTools Protocol (CDP) 实现的，支持后台无头浏览器操作。安装命令：

/skill install browser

典型用法："Go to Amazon.com, search for 'ergonomic office chairs under $200', extract the top 5 results with prices and ratings, and save to a CSV."

Pro Tip：配合 cron 使用可实现定时监控。注意设置 realistic delays（2-5 秒）和 rotate user agents 以避免被封。

Skill 2：cron（定时任务）

原生定时任务支持，无需外部调度器。在 HEARTBEAT.md 或 openclaw.json 中配置：

cron:
  - schedule: "0 8 * * *"
    action: "summarize_news"
    channel: "#daily-briefing"

最佳实践：stagger cron jobs（错开执行时间），实现 retry logic with exponential backoff，并定义明确的 failure notification path。

Skill 3：Skill Workshop（自动生成技能）

v2026.7.2 beta 新功能。使用方式：

/skill workshop scan --sessions 30 --conservative

它会分析最近 30 个会话，识别重复模式，并生成可 review 的技能草稿。默认启用自动 approval handling，但建议首次使用时手动 review 每个生成的 skill。

Skill 4：mcp-bridge（MCP 协议桥接）

实验性功能（PR #94400）。配置后，OpenClaw skills 可通过 MCP protocol 被外部客户端调用：

{
  "skillsMcpBridge": {
    "enabled": true,
    "endpoint": "/mcp",
    "lazyLoad": true
  }
}

这让 OpenClaw 成为 MCP 生态的"技能服务器"，Cursor、Claude Desktop 等工具可以直接调用你已安装的 skills。

关键洞察

2026 年的 AI Agent 市场呈现典型的"早期爆发"特征：预算投入快、采用率高，但生产落地和 ROI 兑现严重滞后。Gartner 的警告尤其值得关注——40%+ 项目面临取消风险，主要原因是价值不明确、成本失控、风险管控不足。

这对 OpenClaw 生态的启示：从"炫技 demo"转向"可治理的运营基础设施"。OpenClaw 近半年在 approval gates、compaction timeout、cron reliability、skill provenance 等方面的投入，正是瞄准了这个"治理缺口"。
