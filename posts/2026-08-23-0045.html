版本发布

OpenClaw 2026.8.1 稳定版发布

2026-08-16 发布

本次更新带来多项面向生产环境的核心能力：

  • Trusted-proxy browser pairing：支持从受信任代理身份自动审批新的 Control UI 和 WebChat 设备，非管理员范围权限下仍保持现有设备升级的手动确认。
  • Dashboard MCP apps：可将源自会话的 MCP 应用视图固定为实时 Dashboard 小部件，在沙盒视图中保持工具交互性。
  • Buzz 消息协议支持：完整支持 Markdown 输出，支持普通消息、富内容消息和结构化差异房间消息。
  • External gateway supervision：新增 OPENCLAW_SUPERVISOR_MODE=external 模式，为 OCM 等生命周期管理器提供受控重启和延迟行为。
  • Channel plugin ingress monitors：新增共享插件 SDK 监控，覆盖准入、轮询、清理、认领身份验证等生命周期。

版本发布

OpenClaw 2026.7.2 重大功能更新

2026-07-13 发布

该版本在模型支持、本地推理、会话管理和会议功能方面实现跨越式升级：

  • 模型扩展：新增 Claude Opus 5、Kimi K3、GPT Live realtime 支持，覆盖 Platform API 认证路径。
  • 本地推理： onboarding 期间自动检测本地推理提供商，新增 llama.cpp GGUF 推理和 Baseten Model API 支持。
  • 会话与看板：支持 rewind/fork 和分支切换、会话面板与 Dashboard、归档/可见性/草稿/隐身会话状态。
  • 会议集成：新增 Teams 和 Zoom 会议嘉宾支持，Teams/Zoom/Google Meet 插件默认启用，自动收集持久化会议转录。
  • 跨平台 Quick Chat：macOS 和 Linux 获得 Quick Chat 支持，含流式传输、路由、上下文捕获、听写和模型控制。

⚠️ ClawHub 安全提醒

根据 Palo Alto Networks Unit 42、Snyk、Bitdefender 等多家安全机构 2026 年 2-5 月的审计：

  • ClawHub 上 12-36% 的技能存在漏洞或恶意载荷
  • 341 个恶意技能被确认（包括 Atomic macOS Stealer 投放器）
  • 36% 的技能包含提示注入攻击
  • 恶意技能常伪装成 "Telegram Enhanced Notifications"、"Calendar Sync Pro" 等正常名称

安全建议：

  1. 只安装已验证发布者或官方认证的技能
  2. 安装前阅读技能源代码（Skills 通常只有几百行）
  3. 关注技能的网络请求、文件访问和环境变量读取行为
  4. 定期运行 openclaw security audit
  5. 优先使用已集成 VirusTotal 和 ClawScan 扫描的技能
