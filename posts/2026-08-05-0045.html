📌 核心功能更新详情

Task Brain：SQLite 持久化任务账本

来源：OpenClaw 架构文档 | 2026年

OpenClaw 的核心创新之一是 Task Brain 架构——基于 SQLite 的持久化任务账本，赋予 Agent 以下能力：

  • 任务分解：将复杂目标拆解为可执行步骤
  • 跨会话记忆：上下文在会话间持续保留
  • Heartbeat 机制：每 30 分钟检查一次任务队列，驱动 24/7 自主执行
  • SOUL.md 记忆系统：Markdown 格式的持久化人格与记忆文件

Canvas 可视化引擎

来源：OpenClaw 功能文档 | 2026年

Canvas 是 OpenClaw 的可视化输出引擎，支持：

  • 实时浏览器快照渲染（screenshot + snapshot）
  • 代码执行结果可视化
  • 多模态内容展示（图片、PDF、网页）

与 Hermes Agent 的纯文本输出相比，Canvas 在可视化交互场景下具有明显优势。

Skills 系统：Markdown + TypeScript 插件

来源：OpenClaw 技能开发文档 | 2026年

OpenClaw 的技能体系以 SKILL.md 为核心契约：

  • 每个 Skill 是一个 Markdown 文件，定义 Agent 的行为规范
  • 支持 TypeScript 编写自定义工具逻辑
  • 技能可打包为 npm 包，通过 ClawHub 分发
  • 官方 awesome-openclaw-skills 精选集按 20+ 类别组织

与 Hermes Agent 的"自动生成 Skills"不同，OpenClaw 采用"手动编写 + 社区共享"模式，更强调可控性和可审计性。

🔱 Hermes Agent（Nous Research）—— 自进化 Agent 标杆

来源：Nous Research GitHub / CSDN / 博客园 | 2026年4-8月

Hermes Agent 是 OpenClaw 最直接的竞争者，两者代表 AI Agent 框架的两种哲学：

维度 OpenClaw Hermes Agent
核心哲学 网关优先，广覆盖 + 手动控制 Agent 循环优先，深度学习 + 自进化
GitHub Stars 373K+ 160K+（2026年4月 v0.8.0 时 53.2K）
技能生成 手动编写 SKILL.md 自动生成 + 自我改进
内存系统 SQLite + Markdown 三层：技能记忆 + 对话记忆 + 用户建模
容器沙箱 Docker 沙箱 六后端沙箱（Docker / Modal / Singularity 等）
MCP 安全 基础支持 OAuth 2.1 安全层
训练数据 无 内置 RL 训练管道 + 轨迹导出
渠道覆盖 50+ 16+

关键动态：2026 年 5 月 10 日，Hermes Agent 在 OpenRouter 的日活 token 处理量达 224B，首次超越 OpenClaw 的 186B。但 OpenClaw 在 GitHub Stars（373K vs 160K）和累计使用量上仍保持领先。

适用场景建议：需要持久化研究助手、子代理并行和 MCP 集成的 AI 开发者选 Hermes；需要覆盖国内全平台、快速零配置落地的企业用户选 OpenClaw。

🛡️ 安全开发建议

来源：Oasis Security / OpenClaw 安全指南 | 2026年
  • 安装 Skills 前检查来源，优先使用官方或高星社区技能
  • 远程部署务必启用 token 鉴权：auth.mode: "token"
  • 定期运行 openclaw doctor 检查配置安全
  • 敏感操作（文件删除、API 调用）建议添加二次确认
  • 关注 ClawHub 安全公告，及时更新有漏洞的技能
