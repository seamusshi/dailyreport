📚 精选 Skill 学习指南

新手入门：编写第一个 Skill

# 1. 创建 Skill 目录
mkdir -p ~/.claw/skills/readme-writer

# 2. 编写 SKILL.md（唯一必需文件）
cat > ~/.claw/skills/readme-writer/SKILL.md << 'EOF'
---
name: readme-writer
description: Creates professional README.md files for software projects.
  Use when user asks to "write a README", "create a readme",
  "document this project", "generate project documentation".
---

# README Writer

## Step 1: Gather project context
Check for package.json, pyproject.toml, go.mod, LICENSE, .env.example

## Step 2: Write the README
Use this structure: Features, Prerequisites, Installation, 
Configuration, Usage, License

## Step 3: Write to disk
Once content is ready, write using write tool

## Step 4: Quality check
- No placeholder text remains
- Every command is accurate
- License matches LICENSE file
EOF

# 3. 重启 OpenClaw 会话即可使用

进阶：多文件 Skill 结构

my-skill/
├── SKILL.md          # 必需：指令与元数据
├── scripts/          # 可选：可执行代码
│   └── deploy.sh
├── references/       # 可选：按需加载的文档
│   └── api-reference.md
└── assets/           # 可选：模板与资源
    └── template.json

渐进式披露设计确保：启动时仅加载 metadata（约 100 tokens），实际触发时才加载完整内容，支持大量 Skills 共存而不挤占上下文窗口。
