🦞 OpenClaw 官方动态

🔖 最新版本：2026.9.1-beta.1（2026-08-29）

发布时间：2026年8月29日 | 类型：预发布版本

本次 beta 版本聚焦稳定性修复与 Gateway 可靠性，主要改进包括：

  • Gateway 重启恢复 — 保留已准入的重启安全运行状态，保留检查点和最终交付结果（#130491）
  • Gateway 配置观察器交接 — 在观察器确认已提交版本前保留待处理配置写入，修复 config.patch 在同源交接时失败的问题（#131515）
  • Linux 安装器运行时选择 — 使用稳定的 Node 24 LTS 配置，避免新 Linux 安装选择不兼容的预发布版本（#130369）
  • Worker 准入恢复 — 在准入截止和终止后重新启动符合条件的启动，终止死亡 worker 的轮次（#130446）
  • Control UI 代理文件 — 当较旧的读取或列表刷新稍后完成时，保持已确认的保存和文件元数据完整（#130468）
  • 模型目录激活 — 在自动 provider-plugin 激活后保留模型浏览能力（#130481）

预发布提示 建议在可丢弃或非关键环境中测试，确认稳定后再考虑生产部署。

OpenClaw 创始人 Peter Steinberger 于 2026 年 2 月 14 日加入 OpenAI，同时 OpenClaw Foundation 正式成立，标志着项目从个人开源项目向社区化治理转型。OpenClaw 最初于 2025 年 11 月以 "Warelay" 之名发布，后因 Anthropic 商标投诉更名为 "Moltbot"，最终于 2026 年 1 月 30 日定名为 "OpenClaw" 并引发病毒式传播。

从 2026 年 1 月的约 5 万 Stars 到 5 月的 37 万+，OpenClaw 创下 GitHub 历史上最快增长纪录，引发 Sam Altman、Mark Zuckerberg 等行业领袖关注。

📌 核心功能更新详情

🛡️ Auto Mode 企业级执行防护（2026.05.31）

OpenClaw 于 5 月 31 日推出 auto mode，引入企业主机执行防护机制。该模式在保持 Agent 自主执行能力的同时，增加了企业级的安全护栏，限制 Agent 的敏感操作范围，降低恶意 Skill 和提示注入攻击的风险。

企业级 安全

🔌 MCP 协议支持深化

OpenClaw 持续深化 MCP（Model Context Protocol）支持，通过 MCP Builder Skill 可快速将内部 REST API 包装为 MCP 服务器。社区已产出大量 MCP 相关教程和工具，包括 FastMCP（Python）和 TypeScript 脚手架支持。

关键数据：截至 2026 年 8 月，MCP 协议已有 9,400+ 服务器实现，成为 Agent 互操作的事实标准。

🧠 记忆与个性化系统

OpenClaw 支持持久化记忆（LanceDB 等向量存储）和 RL 个性化反馈机制，让 Agent "越用越懂你"。配合 SOUL.md 人格定制文件，用户可以为 Agent 定义独特的性格、偏好和行为模式。

📖 Skill 开发入门路径

对于不想手动编写 SKILL.md 的用户，EasyClaw 和 KimiClaw 支持自然语言 Skill 创建：

  1. 用自然语言描述需求，如 "每周一早 8 点拉取 Shopify 上周销售数据，发 Telegram 摘要"
  2. Agent 自动生成 SKILL.md 草稿
  3. 用户审核并批准后激活

对于开发者，推荐路径：阅读 skill-creator Skill → 使用 superpowers 提升工程能力 → 通过 mcp-builder 扩展集成能力。
