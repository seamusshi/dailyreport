📌 核心功能更新详情

Markdown驱动多Agent协作：文件即协议

社区近期涌现的Markdown驱动多Agent架构引发广泛讨论。用6个Agent组建永不停歇的工作团队，其协调机制不是API调用、不是消息队列、不是编排框架——而是文件系统上的Markdown文件。

架构核心优势：

  • 零依赖高可靠：文件没有认证问题、没有API速率限制、没有服务崩溃风险
  • 人类可审计：Markdown既是机器协作协议，也是人类可读的工作日志
  • 松散耦合：Dwight写完intel/DAILY-INTEL.md，Kelly读取起草推文，Rachel读取写LinkedIn内容——流水线自然形成

这种「简单到不可能崩溃」的架构，在AgentOps和可观测性日益重要的企业场景中，具有独特的吸引力。

心跳自愈机制：Cron任务的保险丝

定时任务失败的原因多样：机器重启、任务卡住、网络断开、API超时。社区最佳实践在HEARTBEAT.md中设置安全网关：

  • 每次心跳检查各定时任务lastRunAtMs是否超过26小时
  • 过期则通过CLI强制触发：openclaw cron run <jobId> --force
  • 完全自动修复，无需人工干预，已在多个生产环境验证

Skill 3：心跳自愈系统搭建

确保定时任务永不失联的关键配置：

# HEARTBEAT.md 配置示例
jobs:
  daily_report:
    cron: "0 0 * * *"
    max_silence_ms: 93600000  # 26小时
    auto_recover: true
    recover_command: "openclaw cron run daily_report --force"
  
  health_check:
    cron: "0 */6 * * *"
    checks:
      - job: daily_report
      - job: backup
      - job: sync
