🚢 v2026.4.19-beta.1：子代理身份路由修复

发布时间：2026-04-19 | 来源：OpenClaw Changelog

本次 Beta 版本修复了一个严重影响多代理部署的问题：跨代理子代理 spawn 现在通过目标代理绑定的渠道账户进行路由，而不是在共享房间和多账户设置中继承调用者的账户。这意味着在生产环境中运行多个代理的团队将不再遇到"为什么这个回复来自错误的身份？"的问题。

核心改进：

  • 跨代理子代理身份路由修复（CVSS 相关）
  • 状态报告更诚实：Codex 会话总数不再膨胀新上下文使用量
  • 浏览器控制硬化：CDP 诊断现在可以区分 HTTP 发现、WebSocket 发现、SSRF 验证或版本健康检查的失败

  • 危险的内置代码扫描发现现在对插件和 Skill 安装默认失败关闭
  • 不受信任的工作区 .env 文件无法走私运行时控制覆盖
  • 远程节点 exec 事件被显式标记为不受信任的系统事件
  • 浏览器操作在交互驱动的导航后重新检查被阻止的目的地

Skill 4：从零自制 Skill（2026 实测教程）

必学 难度：⭐⭐

核心认知：Skill 本质是给 AI 的"操作说明书"，核心仅需一个 SKILL.md 文件，明确触发条件、工作流程和输出格式。

文件结构：

skills/your-skill/
├── SKILL.md          # 核心：触发条件 + 工作流程 + 输出格式
├── references/       # 辅助参考文件（可选）
└── scripts/          # 辅助脚本（可选）

SKILL.md 三段式写法：

  1. Frontmatter（必须有）：name + description（写清楚适合场景和 NOT for）
  2. 触发条件：When to Run —— 自然语言描述启动时机
  3. 工作流程：Workflow —— 写命令，不写意图

发布到 ClawHub：

npm install -g clawhub
clawhub init
clawhub login
clawhub publish
