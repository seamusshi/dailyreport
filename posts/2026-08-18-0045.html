🦞 OpenClaw 官方动态

ClawHub 技能生态爆发

OpenClaw 技能生态系统迎来爆发式增长。VoltAgent 维护的 awesome-openclaw-skills 仓库已收录 5300+ 社区构建技能，覆盖编码代理、IDE集成、安全审计、智能家居、健康追踪、个人财务等数十个类别。

ClawHub（clawhub.com）正式上线，提供技能的发现、安装、更新和发布全流程支持。开发者可通过 clawhub install <skill-slug> 一键安装技能。

Agent Skills 开放标准获广泛采纳

OpenClaw 推动的 Agent Skills 开放标准（以 SKILL.md 为核心的技能目录格式）已获得 16+ 平台采纳，包括 Claude Code、Codex、Cursor、OpenCode 等。skills.sh 作为技能包管理器，支持语义化版本控制，生态地位类似 npm 之于 Node.js。

学术论文《Agent Skills: A Data-Driven Analysis》指出，skills.sh 记录的技能数量在 2026 年初已突破 40,000，OpenClaw GitHub Stars 单日激增超 25,000，总星数突破 170K（最新数据显示已超 386K）。

Skill 安全成为焦点

Liu 等人发表的大规模实证研究收集了 42,447 个技能，系统分析 31,132 个后发现 26.1% 存在至少一种漏洞，涵盖提示注入、数据泄露、权限提升和供应链风险。SkillFortify 等安全扫描工具开始支持 OpenClaw Skills 格式（SKILL.md）的自动检测。

DigitalOcean 官方指南建议用户：审查代码后再安装、使用 ClawDex 扫描已知漏洞、及时卸载未使用技能、对连接敏感信息的实例保持高度警惕。

Hermes Agent · 自进化能力持续领先

Nous Research 出品的 Hermes Agent 以 191K GitHub Stars 紧追 OpenClaw，其核心差异化在于自进化能力：

  • Agent 完成复杂任务后，自动分析路径并提炼为可复用工作流
  • Skill 是"Agent 写的、动态的"，而非"人写的、静态的"
  • 内置 Atropos RL 环境支持强化学习训练

实测案例显示，用户可通过"Agent 装 Agent"的方式，用 OpenClaw 全程操控远程 VM 安装配置 Hermes，并在过程中触发自我进化，生成高质量 Skill。

阿里云企业级部署：从原型到生产

阿里云提供三层部署架构：

  • SAS（轻量应用服务器）：适合原型验证，OpenClaw 预配置镜像，10 分钟上线
