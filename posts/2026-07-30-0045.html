📌 核心功能更新详情

A2UI（Canvas 远程 UI）：Agent 的可视化交互革命

OpenClaw 最新引入的 A2UI 框架允许 Agent 在远程 Canvas 上渲染交互式 UI，用户可通过浏览器实时查看和操作 Agent 的执行界面。这解决了长期以来"Agent 在黑暗中干活"的痛点——用户终于能看到 AI 在做什么。

典型场景：Agent 操作浏览器抓取数据时，用户可在 Canvas 上实时观察页面跳转、元素定位过程，必要时人工干预。

技术架构：Agent 侧生成 UI 描述 → Gateway 渲染为 HTML/Canvas → 用户通过 Web 或 IM 内嵌页面交互。支持 snapshot、eval、a2ui_push 等原子操作。

MCP 原生支持：从 Skill 到通用工具协议

2026 年 MCP（Model Context Protocol）已成为 Agent 工具调用的实事标准。OpenClaw 的 MCP 支持包括：

  • Inbound MCP：外部 MCP client 调用 OpenClaw skills（通过 /mcp endpoint）
  • Outbound MCP：OpenClaw Agent 调用外部 MCP servers（如 SQLite、Git、Browser）
  • Lazy loading：skill 的 MCP server 按需启动，闲置 5 分钟自动释放，降低资源占用

这意味着 OpenClaw 的 5700+ skills 正在成为整个 MCP 生态的"工具超市"，任何兼容 MCP 的 AI 工具都能直接消费。

🟠 竞品动态

Hermes Agent（Nous Research）~110K ⭐

2026 年 7 月 20 日，Towards AI 发布 《Hermes vs OpenClaw: 2026 Guide》，将两者的差异概括为：

  • OpenClaw：平台型框架，强调工具连接与任务编排，适合标准化、可重复的业务流程
  • Hermes：学习型框架，强调长期记忆、任务反馈与能力优化，适合复杂、长期优化的场景

Hermes 的核心差异化：

  • 自写技能（Self-writing Skills）：Agent 根据历史经验自动生成可复用的 SKILL.md，无需人工编写
  • 三层记忆：skill memory + conversational memory + user modeling
  • Python 生态：基于 Python，需要 GPU + Ollama，setup 时间数小时
  • 零遥测：完全本地运行，无任何数据上传

选型建议（来自社区共识）：编码为主选 Claude Code；灵活扩展选 OpenClaw；长期自主运行选 Hermes；需要审批链选 OpenHuman。

📚 精选 Skill 学习指南

Skill 1：kimi_search（情报搜集利器）

基于 Kimi 搜索引擎的 skill，支持实时网络搜索，返回带引用的 AI 合成答案。是 Daily Report 类任务的必备技能。

典型用法：kimi_search query="OpenClaw 最新 release" freshness="day"

参数技巧：freshness 支持 day/week/month/year；country 支持 US/DE/ALL；date_after/date_before 可限定时间范围

组合场景：kimi_search + summarize + feishu-doc → 自动搜集行业资讯，生成摘要并写入飞书日报

Skill 2：kimi_finance（实时股票数据）

接入同花顺数据，支持 A 股（.SH/.SZ/.BJ）、港股（.HK）、美股（.US）实时行情。A 股支持历史分钟 K 线，港股仅交易时段可用，美股仅支持 realtime_price。

典型用法：kimi_finance ticker="000001.SZ,AAPL.US" type="realtime_price"

注意事项：查询前务必用 kimi_search 验证股票代码准确性，错误代码会静默返回错误数据

Skill 3：agent-browser（浏览器自动化）

2026 版基于 Chrome DevTools Protocol，支持后台无头浏览器操作。新增 realistic delays 和 user agent rotation，反爬能力大幅提升。

进阶技巧：多步交互时设置 2-5 秒延迟，配合 feishu-im 实现"监控 → 提取 → 通知"全链路自动化

Skill 4：feishu 全家桶（文档/表格/任务/日历）

OpenClaw 的飞书集成能力在 2026 年大幅增强，官方 skills 覆盖：

  • feishu_create_doc / feishu_update_doc：Markdown 转飞书云文档，支持 overwrite/append/replace 等多种模式
  • feishu_sheet：电子表格读写，支持 info/read/write/append/find/export
  • feishu_task_task：任务管理，支持创建/查询/更新
  • feishu_calendar_event：日程管理，自动展开重复日程

组合场景：browser 抓取数据 → sheet 存储 → task 分配跟进 → calendar 设定 deadline → doc 生成报告，形成完整办公自动化闭环。

Skill 5：cron（定时任务调度）

OpenClaw 内置的 cron 系统支持精准定时与 agentTurn 任务：

  • schedule 类型：at（一次性）、every（循环间隔）、cron（表达式）
  • payload 类型：systemEvent（注入系统事件）或 agentTurn（运行 agent）
  • 交付模式：announce（发送到聊天频道）或 webhook（HTTP POST）

避坑指南：整点任务（如 10:00、14:00）竞争激烈，建议错峰 ±15 分钟设置，失败率显著降低。
