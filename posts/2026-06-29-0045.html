竞品动态

字节跳动 · ArkClaw（火山引擎）

ArkClaw 是字节跳动旗下火山引擎推出的云端托管版 OpenClaw，核心定位是“零门槛、轻量化、7×24 小时在线”。

  • 定价策略：Lite 版月费低至 8.9 元（按请求次数计费），对比原生 OpenClaw 自部署月均约 1200 元（云主机+模型费用）大幅降低门槛。
  • 核心能力：一键云端部署、专属 ECS 资源、自动升级、飞书/钉钉/企微集成、火山方舟 Coding Plan 套餐绑定、数据隐私保护（不暴露公网端口）。
  • 生态对比：官方发布 ArkClaw vs Coze vs GPTs 深度评测，明确 ArkClaw 聚焦“执行型智能体”，Coze 聚焦“低代码创作平台”，GPTs 偏向“通用对话助手”。
  • 迁移能力：支持本地 OpenClaw 数据平滑迁移至云端，保留记忆、技能与使用习惯。

Nous Research · Hermes Agent

Hermes Agent（昵称“爱马仕”）是 Nous Research 开发的自我改进型开源 AI Agent 框架，2026 年 2 月开源，发展势头迅猛。

  • GitHub 数据：Stars ~35.7k，Forks ~4.5k，最新版本 v0.8.0（2026.4.8）。
  • 核心差异化：自我改进——从经验中自动创建并优化技能；持久记忆——三层记忆系统（短期/长期/共享），跨会话持续学习；动态编排——Router 机制支持根据任务状态自动分配 Agent，支持“回退”与循环控制。
  • 模型兼容：支持 200+ 模型，包括 GPT-4o、Claude、DeepSeek、Kimi、GLM 等，切换模型仅需改一行 base_url。
  • 企业选型定位：在“2026 AI Agent 框架选型指南”中，Hermes Agent 被定位为“最快接入 MCP/Function Call”的轻量工具链，OpenClaw 偏“网关治理”，OpenHuman 偏“人机协作复核”。

精选 Skill 学习指南

  • tavily-search：为 OpenClaw 装上“AI 的眼睛”。安装命令：clawhub install tavily-search。支持实时联网搜索、带来源的结构化结果、代码报错自动搜索解决方案。适用场景：新闻追踪、价格监控、技术文档查询。
  • self-improver：让 OpenClaw “越用越聪明”。安装命令：clawhub install self-improver。记录用户操作习惯与纠正指令，自动优化后续输出格式。避坑：纠正指令需明确，如“不要使用专业术语”而非“简单点”。
  • code-generator：多语言代码生成与调试助手。支持 Python、JavaScript、Java 等。示例指令："帮我写一个 Python 脚本，批量读取 Excel 的‘销售数据’工作表，统计各产品销售额并生成新报告"。
  • yahoo-finance：金融数据查询 Skill，适用于美股分析，可获取 PE、EPS、财报数据等。A 股用户可依赖内置浏览器工具或自建 Python Skill 集成 akshare。
