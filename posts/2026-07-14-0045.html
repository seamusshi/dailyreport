🦞 OpenClaw 官方动态

🔄 品牌统一：Clawdbot → Moltbot → OpenClaw → Clawbot

OpenClaw 项目经历了多次品牌更迭。最初名为 Clawdbot，后因商标纠纷被迫更名为 Moltbot（Clawbot 与 Anthropic 冲突），随后改为 OpenClaw 以强调开源属性。目前官方已统一使用 Clawbot 作为正式品牌名称，所有渠道（GitHub、文档、社区）均已迁移。

  • 核心架构保持不变：Gateway（网关）、Agent（智能体）、Skills（技能）、Memory（记忆）四层设计
  • 支持本地运行：macOS、Windows、Linux 全平台，数据留存在本地，隐私优先
  • 多平台消息接入：WhatsApp、Telegram、Discord、Slack、Signal、iMessage、微信、QQ、钉钉、飞书等
  • 创始人 Peter Steinberger 已加入 OpenAI，项目移交开源社区基金会持续维护
来源：OpenClaw 官方公告 / GitHub / 开发者博客 | 2026年

📊 ClawHub 技能市场：31,000+ Skills 背后的安全隐忧

ClawHub 作为 OpenClaw 官方技能市场，截至 2026 年 3 月已累计收录 31,000+ 验证 Skills，三个月内安装量突破 15 万次。但 rapid growth 也带来了安全风险：

  • 安全审计发现 820+ 恶意技能，占比约 7.6%，包括 credential harvesters（凭证窃取）、cryptominers（加密货币挖矿）和钓鱼插件
  • 学术机构发布首篇系统研究论文《Red Skills or Blue Skills?》，首次量化分析 ClawHub 的安全风险面
  • 社区安全工具 ClawDex 上线，可扫描已知漏洞；官方推出 clawaudit 自动化安全审计框架（coming soon）
  • 建议用户安装前检查权限、阅读源码、在隔离环境测试，使用 openclaw skill inspect <skill-name> 审查
来源：arXiv 2604.13064 / Tom's Hardware / The Verge / ClawHub 统计 | 2026年3月

🧠 Moltbook 社交层：140 万 Agent 自主互动

OpenClaw 生态的社交实验平台 Moltbook 已吸引 140 万活跃 Agent，这些 AI 代理在无人工干预的情况下自主发帖、协作、形成集体数字智能。这标志着从「单 Agent 工具」到「集体智能生态」的关键转变。

  • Agent 可自主发布内容、回复其他 Agent、建立协作关系
  • 涌现出独特的「数字文化」和互动模式
  • 专业人士应关注如何「编排」这些 Agent 社区，而非仅构建孤立机器人
来源：TechTarget / Skywork AI | 2026年2月

📌 核心功能更新详情

🎯 Skills 系统：模块化扩展的核心

OpenClaw Skills 是基于 SKILL.md 规范的模块化能力单元，采用 YAML frontmatter + Markdown 指令的格式：

  • 创建门槛低：任何开发者可在 30 分钟内创建并发布 Skill
  • 安装便捷：openclaw skill install <skill-name> 一键安装
  • 安全审查：openclaw skill inspect <skill-name> 预先检查权限
  • 多源获取：ClawHub、GitHub 私有仓库、npm 包、本地文件夹均可

目前 Skills 覆盖八大场景：编码开发、生产力工具、数据分析、DevOps、AI/ML、社群运营、内容创作、安全合规。

来源：OpenClaw 官方文档 / DigitalOcean / Lumadock | 2026年

🔐 安全体系强化

面对 820+ 恶意技能的挑战，OpenClaw 社区和官方正在多维度加强安全：

  • credential-manager：强制安全基础，Agent 密钥集中管理
  • authensor-gateway：技能市场 fail-safe 策略门控
  • agent-security-harness：AI Agent 线协议安全测试
  • domain-trust-check：访问 URL 前自动检查钓鱼/恶意站点
  • skill-provenance：版本追踪与完整性验证
来源：ClawHub Security / awesome-openclaw-skills | 2026年

📚 精选 Skill 学习指南

🔧 ssh-remote：远程服务器管理

通过自然语言管理远程服务器，无需记忆 SSH 语法。

  • 运行诊断、部署代码、检查日志、管理服务
  • 安装：openclaw skill install ssh-remote
  • 安全提示：通过配置文件限制可连接的主机

📸 screenshot-ocr：截图文字识别

捕获屏幕截图并提取文字，评分 4/5 星。

  • 适用场景：文档工作流、读取错误弹窗、纸质文本数字化
  • 安装：openclaw skill install screenshot-ocr

🧠 2nd-brain：个人知识库

捕获和检索关于人、地点、餐厅、游戏、科技的信息。

  • 长期记忆管理，跨会话保持上下文
  • 安装：openclaw skill install 2nd-brain

📊 weekly-ops-report：运维周报生成

从日志和工单系统自动生成运维周报。

  • 读取最近 7 天日志，提取 incidents、recurring warnings、changes
  • 如果安装了 gh/jira CLI，自动拉取 merged PRs 和 closed issues
  • 关键 guardrail：绝不伪造 PR 编号或事件计数
