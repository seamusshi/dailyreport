📌 核心功能更新详情

Skill Workshop：AI 自动为你写技能

这是 2026 年 OpenClaw 最具颠覆性的功能之一。Skill Workshop 会扫描你的历史会话，识别重复出现的模式，然后生成保守的、可 review 的技能草稿。

工作流程：识别触发条件 → 提取工具链 → 生成 SKILL.md → 标记需人工确认的参数。这意味着 Agent 可以从"执行者"进化为"学习者"。

使用方式：

/skill workshop scan --sessions 30 --conservative

Skills MCP Bridge：技能即工具，打通生态

OpenClaw 的 5700+ 社区技能正在变成整个 MCP 生态的工具库。核心机制：

  • 每个 Skill 通过 JSON-RPC handler 暴露为 MCP tool
  • Lazy HTTP server loading：只有被调用时才启动 skill 的 MCP server
  • Optional /mcp endpoint：让外部 MCP client 也能调用 OpenClaw skills

这意味着 Cursor、Claude Desktop、ChatGPT 等工具可以直接调用你在 OpenClaw 里安装的 weather、stock_finance_data 等 skill。

自我优化引擎：Agent 的"元认知"

自我优化引擎让 Agent 在执行完复杂任务后，自动评估自身性能，提取可复用的推理模式。实测数据显示：经过 10-20 次相似任务后，执行速度可提升 2-3 倍。

🟠 竞品动态

Hermes Agent（Nous Research）~140K ⭐

2026 年 2 月 25 日发布，开源 Agent 领域最大黑马。核心差异化在于"自改进技能系统"：

  • 三层记忆系统：skill memory（技能记忆）、conversational memory（会话记忆）、user modeling（用户建模）
  • 闭环学习：任务完成后自动评估 → 提取可复用模式 → 持久化为 SKILL.md → 下次直接调用
  • 支持 16+ 消息平台：Telegram、Discord、Slack、WhatsApp、Signal、钉钉、飞书、企业微信等
  • 支持 MCP 协议扩展工具覆盖，零遥测、完全本地运行

与 OpenClaw 的对垒：OpenClaw 胜在生态广度（5700+ skills、多模型支持、ClawHub），Hermes 胜在进化深度（自改进、持久记忆、本地优先）。面试真题中的选型建议：编码为主选 Claude Code；需要灵活扩展选 OpenClaw；长期自主运行选 Hermes。

ArkClaw（字节跳动 / 火山引擎）

2026 年 3 月 9 日正式上线的云端 SaaS 版 OpenClaw，主打"零门槛、轻量化、7×24 在线"。

  • 一键云端部署，无需本地配置或编写代码
  • 一对一专属 ECS 资源，不暴露公网端口
  • 集成豆包 API，支持 Doubao-Seed-2.0、Kimi2.5、MiniMax2.5、GLM 等主流模型
  • 订阅火山方舟 Coding Plan 即可使用，告别 Token 按量计费焦虑
  • 2026 年 3 月 24 日起，Coding Plan Lite 新购用户不再赠送 7 日免费体验

字节跳动同时推出 ByteClaw（企业版），支持统一身份认证、访问控制与权限管理。

阿里 CoPaw / QwenPaw / JVSClaw

阿里云在 2026 年 2-3 月密集推出三款 OpenClaw 相关产品：

  • CoPaw（2月28日）：开源桌面 Agent 平台，支持一键本地/云端部署，可基于 CoPaw 二次开发，自由接入本地模型、编写 Skill 和接入专属消息应用
  • JVSClaw（3月13日）：零代码三步部署 OpenClaw，支持手机、网页、iPad，无需接入即时通讯工具
  • 百炼 Token Plan：轻量服务器 38 元/年起即可部署 OpenClaw，支持多模型切换，Coding Plan 按次收费替代按 Token 计费

📚 精选 Skill 学习指南

Skill 1：agent-browser（浏览器自动化）

2026 版 OpenClaw 预装 agent-browser v0.2.0，基于 Chrome DevTools Protocol 实现，支持后台无头浏览器操作。

典型用法："访问百度热搜榜，提取今日 Top 5 热点新闻"

进阶用法：多步网页交互（打开链接 → 输入关键词 → 点击按钮 → 提取结果）

Pro Tip：设置 realistic delays（2-5 秒）和 rotate user agents 避免被封。

Skill 2：email（邮件智能处理）

安装量最高的邮件类 Skill（ClawHub 安装量 2172），支持多平台邮件管理与自动化。

claw install skill email

组合场景：Email + Summarize → 自动接收工作邮件，提取核心信息并生成摘要，同步至飞书文档。

Skill 3：feishu-doc（飞书文档集成）

官方 Skill，支持飞书文档的读取、创建、更新操作。与 OpenClaw 的飞书消息渠道配合，可实现"聊天中直接操作文档"的闭环。

组合场景：browser + summarize + feishu-doc → 批量抓取行业资讯，自动生成调研报告并写入飞书。

Skill 4：nano-pdf（PDF 编辑与转换）

支持 PDF 编辑、格式转换、内容提取。在文档处理场景中高频使用。

组合场景：nano-pdf + email → 将 PDF 转为 Word，自动发送给指定收件人。

Skill 5：github（GitHub 集成）

支持 Issue 监听、自动分类、PR 审查辅助。典型工作流：

  1. GitHub 监听新 Issue
  2. AI 自动分类和添加标签
  3. 飞书通知相关负责人
