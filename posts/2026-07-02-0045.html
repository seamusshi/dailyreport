🎯 竞品动态

🦊 阿里 CoPaw

评分：8/10

定位："六边形战士"——功能最全的国产开源 Agent 工作站

  • 核心优势：3 条命令完成安装，原生支持钉钉/飞书/QQ，支持本地模型（llama.cpp/MLX）
  • 功能覆盖：数据库管理、API 测试、部署流水线、监控告警全集成
  • 最新进展：HiClaw 1.0.4 接入 CoPaw Worker，内存降至 1/5，支持本地浏览器操作
  • 短板：启动需 2GB 内存，功能太多导致学习成本高，切换模型时卡顿

⚡ 字节 ArkClaw

评分：7/10

定位："闪电侠"——速度最快的云端托管 Agent

  • 核心优势：毫秒级代码补全、文件操作瞬间完成、零配置开箱即用
  • 定价策略：Lite 版月费低至 8.9 元，Pro 套餐含专属 ECS 资源
  • 最新进展：支持 Coze 迁移、OpenClaw 数据平滑导入、多 Agent 协同共享 Coding Plan
  • 短板：快速生成的代码有时需二次修改，错误处理简单，文档待完善

🐧 腾讯 QClaw

评分：未公开

定位：微信生态原生 Agent 方案

  • 核心优势：深度绑定企业微信、微信小程序、腾讯云生态
  • 场景聚焦：客服自动化、社群运营、私域流量管理
  • 竞争态势：在腾讯系产品内体验无缝，但跨平台能力受限
