Microsoft Agent Framework：AutoGen 与 Semantic Kernel 的「统一大婚」

2025 年 10 月微软宣布的 Agent Framework 于 2026 年 6 月进入 1.0 GA。核心变化：

  • 统一继承： 合并 AutoGen 的 conversational multi-agent 抽象与 Semantic Kernel 的 enterprise features（session-based state、middleware、telemetry、type safety）。
  • 双运行时： Python (pip install agent-framework) 和 .NET (Microsoft.Agents.AI)。
  • 模型支持： Microsoft Foundry、Azure OpenAI、OpenAI、Anthropic、Amazon Bedrock、Google Gemini、Ollama 开箱即用。
  • 负责任 AI： 通过 Azure AI Foundry 集成任务合规、PII 保护、prompt injection 防御。
  • 迁移保障： AutoGen 和 Semantic Kernel v1.x 转入维护模式，至少维护一年并提供迁移工具。

对于已投资微软云生态的企业，MAF 是「不用重新选型」的最安全路径。对于多云用户，其跨云模型支持能力也是加分项。

Rasa CALM：企业级 Agent 框架的新标杆

Rasa 在 2026 年 4 月的评测中被多家机构评为「最佳企业级 AI Agent 框架」。其 CALM（Conversational AI with Language Models）架构的核心差异：

  • 确定性治理： Guided Skills 控制高 stakes 工作流，Prompt-driven Skills 处理灵活对话。LLM 理解业务规则，但不直接执行——你定义边界，Agent 留在里面。
  • 原生语音： 内置 Twilio、Jambonz、AudioCodes、Genesys Cloud 连接器，同一套策略跨语音和文本渠道。
  • 自托管默认： 从第一天起就在本地环境运行，Rasa 不托管任何客户数据。
  • Swisscom 案例： 瑞士电信 20 周从原型到生产，自动化率翻倍，运营成本削减 50%。
  • N26 案例： 欧洲数字银行使用 Rasa 处理监管合规客服。

Rasa 的定价基于年度对话量，不按用户或座位收费。社区版免费，企业版定制报价。

📚 精选 Skill 学习指南

OpenClaw 官方 Skills 创建指南

docs.openclaw.ai 更新了完整的 Skills 创建文档，核心流程：

  • 创建目录： mkdir -p ~/.openclaw/workspace/skills/hello-world
  • 编写 SKILL.md： YAML frontmatter 定义元数据，Markdown body 给 Agent 指令
  • 命名规则： 小写字母、数字、连字符；目录名与 frontmatter name 对齐
  • 测试： openclaw agent --message "give me a greeting" 或 /skill hello-world

官方文档强调：Skills 的本质是「教 Agent 何时以及如何使用工具」，不是代码插件，而是运行时指令。

来源： docs.openclaw.ai
