核心功能更新详情

Teams: Claw — 企业级多 Agent 协作

v0.6.0 引入的团队功能是 OpenClaw 迄今最大的架构升级。支持：团队成员共享 Skills 仓库、统一的身份认证与权限管理、跨 Agent 任务委派、团队级会话隔离。企业可以为不同部门配置独立的 Agent 实例，共享核心 Skills 的同时保持数据隔离。这直接对标了 CrewAI 的多 Agent 协作能力。

Docker 沙箱执行环境强化

针对此前曝出的 CVE-2026-25253（CVSS 8.8）漏洞和 ClawHub 上 341 个恶意 Skills 的发现，v0.6.0 大幅强化了执行隔离。默认启用 Docker 容器沙箱，Skills 的执行被限制在独立容器中，即使恶意代码也无法访问宿主文件系统。新增的 execution.sandbox.mode 配置支持 strict / permissive / disabled 三档。

Skills 插件架构重构

全新的 Skills Plugin Architecture 将 Skill 加载机制从简单的 Markdown 读取升级为模块化插件系统。支持：YAML frontmatter 元数据校验、运行时 capability 权限申请、hooks 系统（工具调用前后自动触发）、多语言脚本执行（Python/Node.js/Bash）。这一重构使得复杂 Skills 的开发门槛大幅降低。

Claude 4.7 系列模型接入优化

Anthropic 发布 Claude 4.7 Sonnet / Opus 系列后，OpenClaw 第一时间完成适配。Sonnet 4.7 在 SWE-Bench 编码基准测试中的得分进一步提升，而 OpenClaw 的 Claude Code 集成模式可以直接调用 Sonnet 4.7 进行代码审查和跨文件重构。支持 100 万 token 上下文的 beta 版本适合大型代码库分析。

精选 Skill 学习指南

从零编写第一个 Skill（2026 官方指南）

OpenClaw101.dev 最新教程的核心步骤：

  1. 定义 Skill 边界：用一段话描述"什么时候用、做什么、输出什么"，防止范围蔓延
  2. 创建目录：mkdir ~/.openclaw/skills/your-skill，或使用 npx clawhub create
  3. 编写 SKILL.md：YAML frontmatter 定义元数据（name、version、capabilities），Markdown 正文写指令
  4. 配置触发：heartbeat 定时触发、slash command 手动触发、或 model-invocation 自动触发
  5. 本地测试：openclaw skill test your-skill --task task-name
  6. 安装生效：openclaw skill install ./your-skill 或从 GitHub 直接安装

关键提示：YAML frontmatter 只支持单行值，metadata 用单行 JSON；{baseDir} 模板变量会自动解析为 Skill 文件夹路径。

Skill 安全三重防护（2026 实测版）

针对"利爪浩劫"供应链攻击事件，建立完整防护体系：

  1. 安装前审查：使用 skill-vetter 官方工具扫描，检查是否包含可疑 shell 命令、网络请求、文件系统操作
  2. 安装后扫描：ClawSec（Prompt Security 团队出品）开启自动安全模式，定期扫描已安装 Skills
  3. 运行时隔离：配置 execution.sandbox.mode=strict，所有 Skill 在 Docker 容器中执行，无法触及宿主系统
  4. 凭证保护：API Key、密码放入 secrets 管理器，禁止明文存储在 SOUL.md 或配置文件中
  5. 网络隔离：绑定 127.0.0.1:18789（而非 0.0.0.0），如需远程访问走 VPN 而非反向代理

⚠️ 实测数据：ClawHub 2,857 个测试 Skills 中 341 个存在数据窃取行为，验证 Skills 相对安全（98.5% 可靠），社区 Skills 风险较高（65.1% Beta 插件不可靠）。
