📅 2026-09-03 🏷️ npm: openclaw@2026.9.1 🔗 Release Notes

  • 更安全的更新恢复：更新失败时自动回滚至上一稳定版本，避免"更新后无法启动"的尴尬局面。

📌 核心功能更新详情

v2026.9.1 2026-09-03 Feature

Mermaid 图表全端渲染

这是 2026 年最受社区期待的可视化功能。现在，OpenClaw 生成的任何 Mermaid 语法图表（流程图、时序图、甘特图、类图等）都会在所有聊天界面实时渲染：

  • Control UI：浏览器端直接渲染，支持缩放和拖拽
  • macOS/iOS/Android 原生应用：集成原生渲染引擎，体验流畅
  • 点击放大预览：复杂图表可全屏查看
  • 移动端重试：渲染失败时自动降级为文本或提供重试按钮

对开发者和架构师而言，这意味着与 Agent 讨论系统设计时可以直接"看图说话"，无需再复制粘贴到外部工具。

v2026.9.1 2026-09-03 Feature

快速启动向导：30 秒从零到运行

新安装流程完全重做：

  • 自动扫描 ~/.claude/credentials、~/.codex/credentials 等常见位置
  • 检测已配置的 API 密钥（OpenAI、Anthropic、DeepSeek 等）
  • 一键导入现有配置，无需手动复制粘贴
  • 首次启动自动运行诊断，确保环境就绪

对于从 Claude Code 或 Codex 迁移的用户，这是一个"无痛切换"的入口。

v2026.9.1 2026-09-03 Feature

个人技能库：共享 Gateway 上的私有空间

在团队共享的 OpenClaw Gateway 上，每位用户现在可以维护独立的个人技能集合：

  • 技能仅对自己可见，不影响团队共享技能
  • 支持从 ClawHub 安装到个人空间或团队空间
  • 自动同步：个人技能跟随用户账号跨设备可用

这解决了企业场景中"我想用某个 Skill 但不想打扰同事"的痛点。

v2026.9.1 2026-09-03 Security

更安全的更新恢复机制

版本更新失败时的自动回滚策略：

  • 更新前自动创建完整配置快照
  • 更新后运行健康检查，失败则自动回滚
  • 回滚过程保留用户数据（记忆、技能、任务）
  • Gateway 级别支持：管理员可配置回滚策略

🏛️ Hermes Agent

开源黑马
⭐ GitHub: 178K+ 🔧 40+ 内置工具 💬 27+ 消息平台

Nous Research 2月发布的开源 Agent，核心卖点是"自我改进 + 持久记忆"。通过内置学习循环，Agent 会从每次任务中生成并优化 Skill，越用越聪明。支持 20+ LLM 提供商（OpenRouter、Claude、GPT、本地模型），MIT 许可证完全免费。已推出 Blank Slate 模式（从零定制）和桌面应用（macOS/Windows/Linux）。

vs OpenClaw： ✅ 自我改进能力 ✅ 跨平台消息支持 ❌ CLI 优先，门槛较高 ❌ 文档仍有缺口
