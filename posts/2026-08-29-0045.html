📌 核心功能更新详情

🖥️ 远程编码会话（Remote Coding Sessions）

这是 v2026.7.2 系列最重要的功能升级。用户现在可以：

  • 在云工作者上运行 Control UI 会话，彻底摆脱本地机器资源限制
  • 在终端中直接恢复 Codex 和 Claude 目录会话，实现"IDE 体验终端化"
  • OpenCode 和 Pi 会话支持直接终端接入，无需跳转 Web UI

对开发者而言，这意味着可以在任何 SSH 终端里拥有一套完整的 AI 编码环境，无需安装 Docker、无需配置 GUI。

🤖 ClickClack Bot 协作

Bot 间协作从"禁止默认"进化为"opt-in 授权"：

  • 每个 Bot 的配置文件独立定义是否允许被其他 Bot 调用
  • 提及门控（mention gating）确保 Bot 不会被动卷入无关对话
  • 重试安全循环保护防止 Bot A 调用 Bot B、Bot B 又调用 Bot A 的死循环
  • 独立线程预算避免单个 Bot 协作耗尽全局资源

这一机制为多 Agent 协作打开了安全通道，让企业级多 Bot 编排成为可能。

🛡️ 安全边界强化

v2026.6.34 及后续版本持续加固 Gateway 边界：

  • 沙盒化浏览器路由、可信 DNS 目标、自定义浏览器源和回环提供者端点拒绝不安全访问路径
  • 提供者流、Discord REST 响应、浏览器 fetch、OAuth 路径和日志对恶意响应大小设限
  • Telegram 凭证不再进入诊断日志
  • 保留会话写入、提供者回退、流进度处理和 stdio 故障的弹性恢复
