🦞 OpenClaw 官方动态

🔖 最新版本：2026.8.1-beta.3（2026-08-24）

发布时间：2026年8月24日 | 类型：Beta 版本

本次版本是 2026.8 系列的重要迭代，核心亮点是GPT-5.6 全系列模型支持与Gateway 可靠性增强：

  • GPT-5.6 Sol, Terra, Luna, and Ultra reasoning support — 全面支持 GPT-5.6 系列推理模型，覆盖 OpenClaw 核心与 Codex runtime（#128263, #128268）
  • Control UI 首次运行引导优化 — 验证模型设置后自动延续至 Custodian 和可选渠道配置，降低新手门槛
  • Puppeteer-compatible CDP relay 支持 — 为配对 Chrome 会话提供兼容 Puppeteer 的 CDP 中继能力，浏览器自动化更稳定
  • Gateway 外部生命周期监管 — 显式的外部 Gateway 生命周期监督，支持验证重启交接
  • SQLite 备份与恢复命令 — 新增紧凑、已验证的 SQLite 备份和定向恢复命令，数据安全更有保障
  • 共享持久化入口监控 — 渠道插件的共享持久化入口监控，提升通道稳定性

版本追踪 截至 8 月 28 日，registry 已标记 v2026.9.1-beta.1（实际为 2026.8.1-beta.4 误发布），npm 安装包可正常获取。

🏛️ OpenClaw Foundation 正式成立（2026年7月）

OpenClaw Foundation 于 2026 年 7 月正式宣布成立，将软件定位为开放、中立、个人化的基础设施。基金会公开谈及扩展稳定发布渠道（extended-stable releases）和严肃工作负载成熟度评分卡（maturity scorecard），标志着项目从纯实验阶段向运营信任阶段过渡。

这一转变对企业用户至关重要——它意味着 OpenClaw 正从"周末玩具"演变为可挂载到邮件、文件、日历和客户通信的系统级基础设施。

📌 核心功能更新详情

🧠 GPT-5.6 全系列模型深度集成

2026.8.1-beta.3 全面接入 OpenAI GPT-5.6 家族，包括：

  • Sol — 标准推理模型，适用于日常任务与代码生成
  • Terra — 增强推理，支持更复杂的多步规划
  • Luna — 长上下文 specialist，适合文档分析与大规模数据处理
  • Ultra — 顶级推理能力，面向科研与高精度任务

Codex runtime 同步适配，开发者可在编码场景中直接调用 GPT-5.6 的 reasoning 能力。

🔒 数据持久化与安全增强

2026.7.2-beta.7 引入的持久化数据能力在 8 月持续完善：

  • 隔离存储（Quarantine Store） — 主数据库损坏时隔离存储可存活，支持崩溃可恢复的 SQLite 快照
  • 会话回滚与分支（Rewind / Fork） — 可从单条消息回滚或分叉会话，并跨分支切换
  • Ticketed MCP Apps — 支持有票证工具和有限上下文更新的 MCP 应用托管
  • Verified SQLite Backup / Restore — 8 月新增的已验证备份恢复命令

📱 移动端与穿戴设备支持

OpenClaw 客户端生态持续扩展：

  • Wear OS 伴侣应用 — 支持 Agent 选择、Talk 控制和音频响应式播放
  • iOS 26 视觉系统适配 — 原生应用刷新，支持 iMessage 投票
  • Android 前台语音唤醒 — 自动化能力达到移动端 parity
  • Control UI 云工作者会话 — 可在云端工作者上运行 Control UI 会话，并在终端恢复

🦐 竞品动态

🔥 Hermes Agent：自进化架构挑战 OpenClaw

发布方：Nous Research | 2026年2月25日开源

Hermes Agent 由 Nous Research（Hermes/Nomos/Psyche 模型家族同一实验室）构建，核心信念是最有价值的 AI Agent 不是无状态任务执行器，而是通过结构化学习循环随时间累积能力的持久化系统。

关键差异化：

  • 执行-反思-沉淀闭环 — 完成任务后评估表现，提取可复用推理模式，作为结构化技能持久化存储
  • 自生成技能 — 无需人工编写，Agent 自动生成并持续优化技能
  • 四层记忆架构 — 提示记忆（热）+ 会话存档（冷）+ 技能（程序性）+ 外部提供者（可选）
  • RL 原生训练 — 集成 Tinker-Atropos RL 流水线，支持 GRPO + LoRA 微调
  • 安全记录 — 截至 2026 年 5 月仅 3 个 CVE，供应链风险远低于 ClawHub

GitHub Stars 持续攀升，被 ArkClaw、JVS Claw 等国产平台作为双引擎之一集成。
