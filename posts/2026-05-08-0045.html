🦞 OpenClaw 官方动态

GitHub 最新发布：v2026.5.5 稳定版

2026 年 5 月 5 日，OpenClaw 发布 v2026.5.5 稳定版本，聚焦架构清理、CLI 增强和插件生态治理。本次更新不含 flashy 新功能，但解决了多个长期存在的稳定性问题：

  • Agents/config 路径解析修复：移除遗留的 main agent 目录辅助函数，模型、认证、网关、捆绑插件和测试助手现在通过 agents.list 和 agent-scope 辅助函数解析默认/会话 agent 目录，插件 SDK 保留向后兼容导出。解决多 agent 场景下的路径歧义问题
  • CLI/status 增强：openclaw status 现在显示所选 agent 的 runtime/harness 信息，终端状态与 /status 运行时行保持一致。感谢 @vincentkoc 贡献
  • Sessions 自动清理：正常 sessions cleanup 期间自动清理旧的未引用 transcript、压缩检查点和 trajectory 文件，防止网关重启或崩溃后的孤儿文件无限累积。修复 #77608
  • Doctor/Codex 路由修复：修复遗留的 openai-codex/* 路由到规范的 openai/*，仅在 Codex 插件安装、启用、贡献 codex harness 且具备可用 OAuth 时选择 agentRuntime.id: "codex"，否则回退到 "pi"
  • 插件同步机制：主机更新期间保持已安装的官方 npm 和 ClawHub 插件（如 Codex、Discord、WhatsApp 和 diagnostics）同步更新，即使已禁用或先前精确固定版本，同时保留第三方插件固定。解决升级后插件版本不一致问题
  • 视频生成改进：在工具边界接受 provider-specific 的宽高比和分辨率提示，将 720P 规范化为 MiniMax 支持的 768P，停止在 Gemini 视频请求上发送 Google generateAudio，使 provider fallback 能从模型特定参数差异中恢复
  • Control UI 优化：支持通过验证过的 gateway.controlUi.chatMessageMaxWidth 设置配置分组聊天消息最大宽度，无需在升级后修补捆绑 CSS。修复 #67935
  • Cron UI 健壮性：忽略无效的持久化 cron 行（缺少有效 payload），防止坏 cron 快照后的空白 Control UI 区域。修复 #55047、#54439

📌 核心功能更新详情

v2026.5.5 技术细节解读

本次更新虽以 "Fixes" 为主，但多项改动直接影响企业用户的运维体验：

  • Agent 目录解析规范化：之前 main agent 目录作为遗留辅助函数存在，在多 agent 切换时可能导致配置加载到错误的上下文。新方案通过 agents.list 显式枚举，配合 agent-scope 辅助函数，确保每个会话加载正确的 agent 配置。对使用多个定制 agent 的企业用户影响显著
  • 会话存储清理：之前网关重启或崩溃后，transcript 和 trajectory 文件会在磁盘上无限累积。新增自动清理逻辑在 sessions cleanup 时扫描并删除无引用的孤儿文件，避免长期运行实例的磁盘爆炸问题
  • 插件生命周期管理：官方插件（npm + ClawHub 渠道）现在会在主机更新时自动同步，即使被禁用也会检查最新版本。这解决了之前 "升级 gateway 后插件版本落后导致兼容性错误" 的常见问题。第三方插件的精确固定版本仍受保护
  • Codex 运行时修复：对使用 OpenAI Codex 插件的用户，自动修复遗留的 openai-codex/* 路由到规范路径，并在 Codex 不可用时优雅回退到 pi harness。避免配置变更后的突然不可用

视频生成多 Provider 适配

v2026.5.5 在视频生成边界做了精细化处理：不同 provider（MiniMax、Google Gemini 等）对分辨率、音频参数的支持差异较大，工具层现在会规范化参数并避免发送 provider 不支持的字段，使 fallback 链能正常工作。这对依赖多模型冗余的企业部署场景尤为重要。
