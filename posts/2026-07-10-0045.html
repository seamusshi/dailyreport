# Weekly ops report

## What it does
Builds a weekly report from local logs and optional issue tracker CLI output.

## Inputs needed
- LOG_DIR: directory with daily log files

## Workflow
1) Verify LOG_DIR exists. If not, ask the user.
2) Read logs from the last 7 days.
3) Extract: incidents, recurring warnings, changes deployed
4) If gh is installed, list merged PRs and closed issues.
5) Produce the report in markdown.

## Guardrails
- Never fabricate PR numbers or incident counts.
- If data is missing, state exactly what is missing.
- Do not restart services or change config.
- Stop after scanning 7 days of logs.

## Failure handling
- If a command fails, include the command and error text then stop.
- If parsing is ambiguous, show the raw lines you used.

设计原则：范围要窄、先只读后写入、破坏性操作 opt-in、常量放配置。
