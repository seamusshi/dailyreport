🔖 最新版本：2026.9.1-beta.1（2026-08-29）

发布时间：2026年8月29日 | 类型：预发布版本

本次 beta 版本聚焦稳定性修复，主要改进包括：

  • Gateway 重启恢复 — 保留已准入的重启安全运行状态，保留检查点和最终交付结果（#130491）
  • Gateway 配置观察器交接 — 在观察器确认已提交版本前保留待处理配置写入，修复 config.patch 在同源交接时失败的问题（#131515）
  • Linux 安装器运行时选择 — 使用稳定的 Node 24 LTS 配置，RPM 安装限定在 NodeSource，避免新 Linux 安装选择不兼容的预发布版本（#130369）
  • Worker 准入恢复 — 在准入截止和终止后重新启动符合条件的启动，终止死亡 worker 的轮次（#130446）
  • Control UI 代理文件 — 当较旧的读取或列表刷新稍后完成时，保持已确认的保存和文件元数据完整（#130468）
  • 模型目录激活 — 在自动 provider-plugin 激活后保留模型浏览能力（#130481）

预发布提示 建议在可丢弃或非关键环境中测试，确认稳定后再考虑生产部署。

📌 核心功能更新详情

🔄 Gateway 重启恢复机制（#130491）

这是一个生产环境关键修复。此前 Gateway 重启时，正在运行的任务状态可能丢失，导致：

  • 定时任务（cron）重复执行或丢失
  • 子代理（subagent）任务结果无法正确回传
  • 检查点（checkpoint）数据丢失

新版本在清理和重复重启时保留已准入的重启安全运行，确保任务连续性。对于依赖 OpenClaw 运行关键业务自动化流程的团队，这是一项必升修复。

🐧 Linux 安装器稳定性改进（#130369）

针对新用户的 onboarding 体验优化：

  • 默认使用 Node 24 LTS（长期支持版），避免预发布版本的不兼容性
  • RPM 包安装限定在 NodeSource 源，减少依赖冲突
  • 解决部分 Linux 发行版上安装失败的问题

配合阿里云百炼的预装镜像，新用户现在可以在 5 分钟内完成从零到可用的部署。

🤖 Worker 准入与自愈能力（#130446）

提升了分布式 worker 的鲁棒性：

  • worker 崩溃后自动重新启动符合条件的任务
  • 正确终止已死亡 worker 的未完成轮次
  • 避免"僵尸任务"导致的资源泄漏

⚠️ Skill 安全使用指南

重要警告：安全审计（Koi Security、Bitdefender、Snyk）发现 ClawHub 上 12-36% 的第三方 Skill 存在漏洞或恶意载荷。

安装前审查清单：

  1. 阅读 SKILL.md 源码 — 不要信任 ClawHub 落地页，直接在 GitHub 仓库阅读实际 SKILL.md 和引用的脚本
  2. 检查发布者信誉 — 一周新账号 + 一个 Skill = 风险信号；寻找有多月记录和真实社区审查的发布者
  3. 固定精确版本 — 永远不要使用 @latest，固定到已审查的确切版本
  4. 避免 curl | bash — 如果 Skill 文档要求将远程脚本通过管道传给 shell，请远离
  5. 审查权限请求 — 摘要 Skill 不需要 shell 执行权限，翻译 Skill 不需要浏览器控制权
  6. 沙盒测试 — 在 NanoClaw 的强制容器隔离中先测试，观察几个会话后再考虑推广到主环境

安全规则：使用 100/3 法则 — 下载量 100+ 且上架 3 个月以上的 Skill 相对安全。
