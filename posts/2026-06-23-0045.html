v2026.6.9 正式发布：Telegram 与 Agent 恢复双升级

来源：GitHub Release | 2026-06-21

最新稳定版 v2026.6.9 已发布，核心亮点：

  • Telegram 富消息交付：支持 HTML 渲染、Markdown 保留、表格安全规范化、进度草稿更忠实展示，提及与分流处理更加精准。

  • 官方 Provider 插件独立发布：外部通道插件在 Gateway 启动时自动加载，StepFun 已可从 npm 和 ClawHub 安装。

v2026.6.10-beta.2 预发布

来源：GitHub Release | 2026-06-22

6月22日发布 beta 预览版，持续修复 v2026.6.9 的边界问题，并引入依赖证据（dependency-evidence）导出机制，提升合规审计能力。

核心功能更新详情

Telegram 富消息支持

v2026.6.9 大幅提升了 Telegram 频道中的消息质量。现在 OpenClaw 可以保留原始 Markdown 格式，安全渲染 HTML 表格，并在进度草稿中更精确地展示命令输出。贴纸路径和@提及机制也得到了正确维护，让 Telegram 成为更可靠的即时交互通道。

Agent 恢复与容错

当 Agent 回合被中断（如网络波动、模型超时）时，新的重试和终端处理机制会确保任务继续推进，而非卡在中途。会话历史修复功能在数据压缩或意外崩溃后，能更好地还原对话状态，减少"重新开始"的尴尬。

Codex 集成深化

在 Codex 工作流中，插件安装不再需要手动确认，SecretRefs 自动管理密钥。远程节点的 exec 能力被正式注册为动态工具，这意味着子 Agent 可以直接在远端服务器上执行命令并获取结果。

ClawHub 安全溯源

Skill 安装现在保留已验证的源代码溯源（provenance），确保从 ClawHub 下载的插件可追溯到原始提交，降低供应链攻击风险。

Kimi Claw（月之暗面）

6月 17 日，Moonshot AI 发布 Kimi Claw 24/7 Benchmark——一套内部长期 Agent 评测体系，覆盖 17 个专业场景、610 个评估点，涵盖软件工程、ML 研究、招聘、交易和营销。该基准每季度更新，用于衡量 Kimi Claw 在持续工作环境中的真实表现。

WorkBuddy（腾讯）

6月5日，在 2026 腾讯云 AI 产业应用大会上，腾讯正式发布 WorkBuddy 企业版（WorkBuddy Enterprise），提供 7×24 专家数字员工、基于"项目"的员工与 AI 协作团队管理、企业级管理后台三大能力。同时发布的办公智能体套件 Agent Suite 通过 One ID 将腾讯文档、腾讯网盘和腾讯乐享原生集成到 WorkBuddy 工作台。

精选 Skill 学习指南

新手必装：tavily-search

作用：为 OpenClaw 添加实时联网搜索能力，打破模型知识截止日期限制。

安装：clawhub install tavily-search

场景：查询最新新闻、竞品动态、价格数据、技术文档。支持带来源链接的结构化结果返回。

办公自动化：file-manager

作用：本地文件管理、文档生成、批量重命名、格式转换。

场景："帮我创建一个名为 test 的文档，内容为 OpenClaw 新手教程""批量将 /tmp 下的 .png 转为 .jpg"。

系统监控：system-info

作用：实时查看系统资源占用、进程状态、磁盘空间。

场景："帮我查看系统资源占用""列出占用内存最高的 5 个进程""检查磁盘空间是否不足"。

安全提醒：Skill 来源审查

CocoLoop 等平台对 Skill 进行 S/A/B/C/D 安全评级，并支持 VM 级隔离。建议新手优先安装 ClawHub 官方推荐或高评分社区 Skill，避免安装来源不明的插件。v2026.6.9 新增了 Skill 溯源验证，确保安装包可追溯到原始 Git 提交。
