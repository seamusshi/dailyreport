📚 精选 Skill 学习指南

1. Self-Improvement Skill — 让Agent学会反省

安装：clawhub install self-improving-agent 或 git clone https://github.com/peterskoett/self-improving-agent

作用：每天自动运行反省流程，记录错误模式并更新行为策略，避免重复犯错。

2. Multi-Search-Engine — 17引擎聚合搜索

安装：clawhub install multi-search-engine

作用：同时调用17个搜索引擎（8个中文+9个国际），无需API Key，适合情报搜集和竞品调研。

3. Memory-Setup — 构建长期记忆

安装：clawhub install memory-setup

作用：配置跨会话持久化记忆，Agent能记住用户偏好、历史决策和项目上下文。

4. Proactive-Agent — 主动提醒

安装：clawhub install proactive-agent

作用：Agent根据日程和任务状态主动提醒用户，从被动响应进化为主动助手。

5. Tavily-Search — 替代Brave的免费搜索

安装：clawhub install tavily-search，每月免费额度充足。

作用：高质量网页搜索，API免费额度 generous，适合日常情报检索。
