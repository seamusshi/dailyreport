📌 核心功能更新详情

个人 GitHub

支持在 profile 中连接 "My GitHub"，PR 可显式使用个人身份发布，切换 session 无需重复验证凭证。（#133799, #136223）

模型设置

Model Setup 清晰区分 account 与 API-key 访问方式，Codex 和 Claude 候选模型显示运行时邮箱，提供商默认页支持自动保存和更简化的模型选择器。（#136521 等）

凭证迁移

共享凭证迁移支持中断恢复、冲突诊断、强制重新登录修复、自定义 provider SecretRefs 持久化等完整生命周期管理。

会话稳定性

修复 reset 后消息丢失、跨 session 镜像投递静默失败、用户消息在重启后保留上下文、代码块重复折叠等关键稳定性问题。

多平台修复

iMessage 私有 API 桥接失败快速退出、Signal 终端状态持久化、Teams 线程上下文保持、Matrix 代码块 spoiler 碰撞修复、飞书文档 API 结果验证等。

内存优化

显著降低 catalog、reset、chat 中的内存峰值，释放 Gateway 和 Activity 保留内存，减少 HTTP 响应体内存占用——VPS 小内存用户受益明显。

启动加速

Doctor 冷启动更快，CLI-only 代码不再在启动时加载，plugin catalog 避免全量扫描，shell 命令冷启动缩短。

📚 精选 Skill 学习指南

本周推荐：browser-use Skill（浏览器自动化）

browser-use 是 OpenClaw 社区目前评分最高的浏览器自动化 skill。 它让 Agent 像人类一样理解网页、点击按钮、填写表单——不需要写 CSS 选择器。

安装步骤
  1. 安装 skill：npx skills add https://github.com/browser-use/browser-use --skill browser-use
  2. 在 openclaw.json 中配置 MCP server
  3. 设置环境变量：LLM 模型、API Key、headless 模式等
  4. 对 Agent 说："去 Amazon 搜索人体工学椅，提取前 5 个结果的价格和评分，保存到 CSV"
适用场景

数据抓取、竞品监控、表单填写、网站巡检、价格追踪

模型要求

Gemini 3.1 Flash、Kimi K2.6、Claude Sonnet 等 vision-capable 模型

注意事项

不解决 CAPTCHA、需尊重 robots.txt、headless 模式可能被反爬
